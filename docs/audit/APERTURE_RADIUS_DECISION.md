# 측광 구경 반지름 — 실측으로 답한 기록

2026-08-17. 사용자: *"원래 권장되는게 구경배수를 쓰면돼 그리고 어차피 apcorr 있으니
괜찮은거아님?"*

## 무엇이 문제였나

Step 7 은 두 개의 원을 쓴다.

- `small_scale` — 실제로 밝기를 재는 원 (`r_ap = k × FWHM`)
- `large_scale` — 구경보정을 뽑는 큰 원 (`r_ref`)

2026-08-16 까지 이 둘은 **아무도 고르지 않은 값**이었다. 코드가 `forced_r_ap_scale`
이라는 아무도 설정하지 않는 이름을 읽고 자기 폴백(0.8 / 2.4)을 집었고, 디스크의 설정
50 개는 1.0 / 3.0 을 요청한 채 무시당했다. 배선하면서 산출물을 지키려고 파일 쪽을
0.8 / 2.4 로 맞췄고, **올리는 것은 별개의 결정으로 남겼다.**

0.8 이 의도처럼 보인 이유는 `small_scale_min` 위에 정확히 앉아서였는데, **그 키를
읽는 코드가 없다** — `optimize_scales` 이하 여덟 개 전부. 설정이 존재하지 않는
최적화기를 광고하고 있었다.

## 이론이 말한 것

가우시안 원형 PSF 의 포함광량:

| 반지름 | 담기는 빛 |
|---|---|
| 0.8 × FWHM | 83.04 % |
| 1.0 × FWHM | 93.75 % |
| 2.4 × FWHM | 99.99999 % |
| 3.0 × FWHM | 100 % |

그리고 **0.8 은 성장곡선의 가파른 곳**이다. FWHM 오차가 광량 오차로 전달되는
상대 민감도가 0.906 인데 1.0 에서는 0.370 — **2.4 배 차이**다. 구경보정은 프레임당
스칼라 하나라 평균만 지우고, 별마다 다른 부분은 남는다. 그래서 이론은 1.0 을 가리켰다.

실측 구경보정도 이론보다 훨씬 크다 — 네 성단에서 1.571~1.610 배(0.49~0.52 등급),
가우시안 예측은 1.204 배. 실제 PSF 날개가 훨씬 두껍다.

## 실측이 말한 것 — 이론과 반대다

다섯 성단 137 프레임을 1.0 / 3.0 으로 재처리하고, **외부 참조등급**(Gaia 유도, 두
실행에서 최대차 `0.00e+00` 로 동일함을 확인)과 별별로 대조했다. 영점 하나만 빼고
남은 산포 — 프레임 스칼라가 지울 수 있는 건 그게 전부다.

| 성단 | 혼잡도 | 0.8/2.4 대비 변화 |
|---|---|---|
| M3 (구상) | 높음 | **+0.016 ~ +0.020** |
| M5 (구상) | 높음 | +0.008 ~ +0.026 |
| M13 (구상) | 높음 | +0.007 ~ +0.012 |
| NGC 6811 (산개) | 중간 | +0.003 ~ +0.004 |
| M67 (성긴 산개) | 낮음 | ≈ 0 |

**15 밴드 중 13 악화, 중앙 +0.0082 등급.** 그리고 악화 폭이 **혼잡도를 그대로
따른다.** 큰 구경이 이웃 별빛을 삼킨다.

### 어느 구경이 범인인가 — 분리 실험

두 knob 을 동시에 움직였으므로 M13·M3 에서 섞인 두 조합을 따로 돌렸다.

| 조합 | M13 평균 | M3 평균 |
|---|---|---|
| 0.8 / 2.4 | 0.1118 | 0.1016 |
| 1.0 / 2.4 | 0.1220 | 0.1191 |
| **0.8 / 3.0** | **0.1109** | **0.1007** |
| 1.0 / 3.0 | 0.1214 | 0.1198 |

**재는 구경이 전부다.** `small_scale` 0.8 → 1.0 이 M13 에서 +0.010, M3 에서 +0.018.
`large_scale` 2.4 → 3.0 은 −0.0009 로 **공짜에 가깝고 아주 살짝 이롭다**(6 밴드 중 5).

물리적으로 앞뒤가 맞는다. **재는 구경은 모든 별에 쓰이니 이웃 오염을 그대로 받는다.**
**참조 구경은 밝고 고립된 별에서만 성장곡선을 뽑는 데 쓰이니** 넓혀도 오염이 안 늘고
날개만 더 담는다.

## 결론

- **`small_scale = 0.8` 을 유지한다.** 이론(민감도 2.4 배)은 실재하지만 성단 장에서는
  이웃 오염에 압도된다 — 그리고 APEX 가 겨냥하는 게 그 성단 장이다.
- `large_scale` 은 3.0 이 2.4 보다 미세하게 낫지만 **0.001 등급**이라, 그것만을 위해
  다섯 성단을 재처리할 값어치는 없다.
- "권장값을 쓰고 apcorr 에 맡긴다"는 일반 측광 실무에서는 옳다. **혼잡장에서는
  성립하지 않는다.** 프레임 스칼라 보정은 평균만 지우고, 오염은 별마다 다르다.

## 남은 것

- **위치 의존 구경보정**(공간 다항식 항)은 아직 없다. 지금은 프레임당 스칼라 하나를
  전부에 바른다. 필요한 재료(밝은 별들의 위치와 각자의 성장곡선)는 이미 코드 안에
  있어서, 위치 의존 부분을 얼마나 줄이는지 측정으로 답할 수 있다.
- 표준적 대안은 셋이고 셋 다 "별마다 직접 재기"가 아니다 — 별마다 재려면 그 별의 큰
  구경 측정값이 필요한데, 그게 있으면 보정이 애초에 필요 없다(순환).
  ① 공간 다항식 ② 가변 PSF 적합(Step 8 이 이것) ③ 다중 프레임 동시 적합
  (Stetson 1990, PASP 102, 932 — DAOGROW).
