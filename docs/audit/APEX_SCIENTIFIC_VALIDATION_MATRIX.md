Legend: **P** = a targeted test/validator exists; **E** = external comparison exists; **S** = synthetic/injection test exists; **R** = real-data evidence exists; **G** = gap or not sufficient for a paper claim. Presence of a pytest is not equivalent to scientific validation.

## Strongest current evidence

The most defensible scientific checks are (i) seeded artificial-star recovery through the production detector/measurement chain, (ii) independent SEP and optional IRAF/DAOPHOT photometry comparisons on explicitly matched coordinates, (iii) per-stage Python `ccdproc` comparison, and (iv) seeded unit/integration coverage for WCS, PSF policy, PDM/SYSREM and isochrone services. These establish reproducible behavior within tested boundaries, not universal accuracy.

## Validation work required before paper freeze

* Publish a single boundary table: camera, filter, FWHM/crowding, magnitude/SNR, sky regime, engine, number of frames/stars, seed, and pass/fail metric.
* Separate “same backend consistency” (`photutils`) from independent references (`sep`, IRAF/DAOPHOT, external catalogues).
* Record skipped/failed external-runtime suites as gaps, never as passing null results.
* Add parameter-sensitivity and negative-control tests for detection, WCS acceptance, aperture correction, error pull, PSF iteration, SYSREM and period FAP.
