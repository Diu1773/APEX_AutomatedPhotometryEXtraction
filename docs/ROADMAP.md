## 0. 현재 위치 (한 단락)

측광 체인(검출→강제측광→ZP)은 독립 소프트웨어(sep/IRAF ~3 mmag)와 외부 표준
(Gaia GSPC, 색 ~10 mmag·편향 없음)으로 **검증 완료**. 이소크론 자동피팅은 EEP
보간 수정으로 **재현 가능**해졌고(6성단, 9 Myr–13 Gyr), 남은 오차는 코드가 아닌
물리 한계([M/H]-적색화 색축퇴 → u밴드가 처방, 나이 희석 → 완전도 우도가 처방)로
**규명 완료**. 배포 인프라(pip/CI/패키징/JOSS 원고/매뉴얼)는 준비됨. 외부 사용자는
아직 0명. 지금의 병목은 코드가 아니라 **출판과 사용자**다.

## 1. 설계 원칙

1. **넓히지 말고 굳힌다.** 새 모드·새 기능은 기본적으로 동결. 범위는 이미 충분.
2. **검증이 곧 제품이다.** APEX의 차별점은 기능 목록이 아니라 "숫자를 믿을 수
   있음"이다. 모든 트랙은 이 신뢰를 강화하는 방향으로만.
3. **정직한 범위 유지.** 못 하는 것(자동 나이의 ~10–20% 한계, 구상성단 혼잡)은
   문서와 논문에 명시한 채로 간다. 과장은 §5 경험보정 사태의 재발이다.
4. **여름방학(7–8월)이 최대 작업 창.** 큰 덩어리(연구급 항목·관측)는 여기 배치.

## 2. Track R — 신뢰성 굳히기 (7월, ~2주)

EEP 버그·MCMC 재현성 버그 둘 다 "테스트가 있는데도" 빠져나갔다. 재발 방지가
다른 모든 트랙의 전제다.

| # | 작업 | 완료 기준 | 규모 |
|---|---|---|---|
| R1 | **과학 회귀 CI** (`apex validate --suite science`) | 번들된 소형 실측 CSV(M67/NGC6811 wide 표 서브셋, <1 MB)로 이소크론 피팅 → 나이/dm/[M/H]가 허용창 이탈 시 CI 실패. 합성 프레임 1장으로 검출→측광 회귀 게이트. | 3–4일 |
| R2 | task #16 마무리 (i-band 오차·색항 잔재) | 진단 이미 완료 → 수정 or "무영향 확인" 문서화 | 1–2일 |
| R3 | task #17 (apcorr 색누수 ≤7e-3) | Step-10 색항 경로 검사, 수정 or 한계 기록 | 1–2일 |
| R4 | 경고 위생 + 의존성 핀 | DeprecationWarning 0, numpy/astropy 상한 명시 (`.venv` 사태 재발 방지) | 반나절 |

> R1이 핵심. "골든 성단 수치가 조용히 틀어지면 CI가 빨간불" — 이번 세션에
> 수동으로 한 일을 기계가 매 커밋마다 하게 만드는 것.

## 3. Track P — 출판 (7월–12월)

### P1. JOSS 소프트웨어 논문 — **즉시** (7월, 1–2주)
- 남은 것: 저자/ORCID 기입, 레포 공개 전환, Zenodo DOI 아카이브, 제출.
- 원고·bib·검증 섹션은 이번 세션에 완비됨. **최소 노력, 최대 레버리지**
  (인용 가능한 출판물 + 외부 피어리뷰 = Track U의 신용 기반).

### P2. RASTI 본논문 — 계획 잠금대로 (8–11월)
- `PAPER_PLAN.md`의 잠긴 결정 유지: **도구+검증 프레임, 이소크론 자동피팅은
  범위 외**, §4는 YZ Boo LC 재현(이미 커밋된 결과로 채움 가능해짐).
- 이번 세션 성과 반영은 §5 Discussion 한 단락(축퇴의 실측 증명 + u밴드 처방
  인용)까지만. 본문 확장 금지 — 스코프 크리프가 최대 리스크.
- 전처리(Step 0) 주장은 메모리 판결대로 "능력 보유 + 합성 검증"으로 한정.

### P3. 이소크론 축퇴 단신 — **별도 2호 논문** (10월–2027 초)
- 이번 세션 결과가 자체로 완결된 이야기다:
  (a) EEP(호장) 보간이 나이 우도의 그리드-스파이크를 제거(재현성 회복),
  (b) 실측 Gaia GSPC로 gri 색축퇴의 [M/H] rail을 직접 시연(M67 −0.50),
  (c) u밴드가 신뢰구간을 ~4× 좁힘(합성 5 regime), (d) 나이 offset은 필터가
  아닌 어두운-MS 희석임을 GSPC 밝은표본으로 분리 증명.
- 형식: RNAAS 단신 또는 RASTI short. **P4(u밴드 실관측)가 성사되면** "예측→
  확인" 구조로 격상 — 이 경우 투고를 관측 후로 미룬다.

### P4. u밴드 관측 제안 (8–9월 관측기)
- 목적: [M/H]-적색화 축퇴를 **데이터로** 깨는 확인 관측. NGC 6811 또는 M67에
  u(or U) 필터 수 시간이면 충분(밝은 별 위주라 얕아도 됨).
- 파이프라인은 이미 u 지원(GUI 경고·R_u 포함) → 관측만 하면 바로 돌아감.
- 실패해도 손실 없음(P3는 GSPC+합성만으로 성립).

## 8. 명시적 비목표 (v1.0까지 하지 않는다)

- **ML/DL 피팅** — 축퇴는 정보 한계로 실증됨(§10.9). u밴드 한 장 > 어떤 모델.
- **새 GUI 기능/모드/화려함** — 신뢰성에 기여하지 않는 확장 일체.
- **다기기 일반화 주장** — 두 번째 기기 사용자가 실제로 생기기 전까지
  (단일 카메라 Moravian C3-61000 명시 유지).
- **컬러(debayer) 지원** — mono 전용 유지.
- **다중노출 CMD(B1/B2)** — 백로그 유지, v1.0 이후.
