현재

수정 후 (구조)

  • 중립 행 + 좌측 3px 상태 바: 완료=초록 바+✓, 진행 가능=액센트 바+○(+연한 액센트 배경), 잠김=회색 바+회색 텍스트
  • 상태 텍스트를 행 우측에 소형으로 (완료/진행 가능/잠김) — "(Locked)" 접미사 제거
  • 현재 위치(다음에 열 스텝) 1개만 액센트 테두리로 강조 — 시선이 "다음 행동"에 꽂히게
  • 진행률 카드에 진행 바 추가 (텍스트만 있는 현재보다 스캔 빠름)
  • 자물쇠는 ICON["locked"](U+FE0E 모노크롬) — 이미 theme에 있으나 StepButton이 미사용

구현 위치: main_window.py StepButton.update_appearance() — 3개 하드코딩 스타일시트를 토큰 기반 1개로 교체.

Step 8 — Target/Comparison Selection

  • 버그버튼 라벨 잘림: lip×2(Flip?), u1, STF 콤보 — 최소폭 미지정으로 글자가 잘림
  • 위계주황 "2D Plot" 하드코딩 — 토글이면 체크형/세그먼트로, 액션이면 중립으로
  • 색상태줄 "Target: (none) Comps: 0 Check: (none)" 빨강/주황/초록 생 텍스트 → status 롤로 통일
  • 가독단축키 힌트(T=target C=comp…)가 6px대 크기로 읽기 불가 → caption 롤(11px)로

Step 9 — Light Curve Builder

  • 위계주황 Run QC + 초록 Auto Use 병렬 — 주 액션 1개만 primary(Run QC), Auto Use는 중립
  • 색하드코딩 안내 배너(#E3F2FD)·경고 배너(핑크) → role="info"/status="warn"
  • 색회색 "Log" 칩 버튼 → ghost 변형(테마 존재, 미적용)
  • 가독QC 테이블 헤더 "Out%"가 "Ɔut%"처럼 잘림 — 컬럼 최소폭
  • 정돈matplotlib 툴바가 회색 밴드로 떠 있음 — 배경 투명/보더 정리

Step 10 — Detrend & Night Merge

  • 위계초록 "Fit & Apply (저장)" 하드코딩 → primary
  • 색핑크 경고 배너 → status="warn"
  • 레이아웃좌측 하단 1/2이 빈 공간 — 날짜/필터 패널 아래 여백이 스트레치를 먹음

Step 11 — Period Analysis

  • 레이아웃Min/Max Period 스핀박스가 창 전체 폭 — 수치 입력은 고정폭(~140px)이 관례
  • 정돈하단 결과 텍스트 영역이 라벨 없이 떠 있음
  • ※ 이 창은 미커밋 변경(period alias 작업)이 있음 — UI 수정 전 커밋 정리 필요

⚠ 툴 캡처는 오프스크린 렌더 — 한글 글리프 일부(merger의 폴더/필터 등)가 깨져 보이는 것은 캡처 아티팩트일 수 있음. 실화면 재확인 후 판정.

Variable Star Analysis

  • 레이아웃좌측 컬럼 하단 절반이 빈 공간, Log 바만 바닥에 고립
  • 가독Status 빨간 장문이 좁은 컬럼에서 3줄 줄바꿈 — 요약+툴팁으로
  • ※ 미커밋 변경 있음 — UI 수정 전 커밋 정리 필요

Exoplanet Transit Analysis

  • 버그라벨에 언더스코어 노출: "Target _Prior Parameters", "Apply Trim _Show" — Qt mnemonic(&) 처리 실수로 추정
  • 위계청록 Scan Period / 초록 Batman Fit / 보라 MCMC — 3색 하드코딩. 주 액션 1개만 primary, 나머지 중립

Eclipsing Binary Analysis

  • 버그라벨/입력 잘림: "Workspac", "esult", "owse" — 좌측 패널 최소폭 부족
  • 위계주황 Scan + 파랑 Fit Eclipse 하드코딩
  • 정돈Fit Eclipse 아래 노란 빈 라벨이 공백으로 떠 있음

Multi-Night Merger

  • 정돈스텝 탭 버튼(Step1~6)이 자체 스타일 — 메인 스텝 리스트와 같은 문법으로 통일 여지
  • 한글 라벨 크기/깨짐은 실화면 재확인 필요 (오프스크린 아티팩트 가능)
