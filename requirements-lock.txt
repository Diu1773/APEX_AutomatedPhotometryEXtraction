# APEX — exact versions that produced the published measurements.
#
# `pyproject.toml` and `requirements.txt` keep version *ranges* on purpose: an
# install should not fail because a dependency moved a patch release. This file
# is the other half of that bargain — the ranges say what APEX runs on, and this
# says what it ran on when the numbers in the paper were measured.
#
# Why it exists at all: on 2026-08-17, five PSF measurements out of 22,305 moved
# by 4.8e-05 mag between two runs of identical code. The cause was scipy 1.18.0
# against 1.17.1 — not noise, not a bug, just a dependency that had moved. All
# five were already flagged bad and none reached a published figure, but the
# next such change might not be so polite (D-011).
#
# Reproducing a published number:
#
#     py -3.12 -m venv .venv-repro
#     .venv-repro\Scripts\python -m pip install -r requirements-lock.txt
#     .venv-repro\Scripts\python -m pip install -e . --no-deps
#
# Normal use — installing APEX to work with — does NOT want this file. Use
# `pip install -e .[gui]`, which follows the ranges.
#
# Every run also records its own environment in the run manifest, so a result
# already carries what made it; this file is what you install to get back there.
#
