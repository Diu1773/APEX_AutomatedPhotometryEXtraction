## 1. 설계 헌법 (전 그림 공통, 예외 없음)

**M. 메시지 규칙**
- M1. **패널 제목은 발견을 진술한다.** "Sky background"(✗) → "하늘 20× 밝아지면 깊이 1.4등급 얕아진다"(✓)
- M2. 그림 하나 = **독자 질문 하나**에 대한 답. 5초 안에 읽혀야 함
- M3. **핵심 수치는 시각 중심에.** 구석 박스 금지
- M4. 정보량 없는 요소(평평한 선, 장식)는 **본문으로 이관하고 그림에서 제거**

**C. 정직성 규칙**
- C1. **AIPPI(저자 자체 도구) 대조 패널 전면 금지** — 검증 근거 아님, provenance로만 본문 언급
- C2. 합성 기반 결과는 **verification**임을 캡션/제목에 드러낼 것 (Oberkampf 어휘, LIT_REVIEW_R2 §E3)
- C3. 비단조·이상치를 감추지 말 것. 단 노이즈면 **끝점 제시**로 정리하고 본문에 명시

**T. 텍스트·라벨 규칙**
- T1. **PNG 안에 suptitle/캡션 굽기 금지** — 캡션은 LaTeX 본문
- T2. **내부 ID 노출 금지.** 축 라벨은 사람이 읽는 표기: `M13 B`, `NGC 6811 V` (✗ `20260611:B`, `AE_UMa:g`)
- T3. 축 라벨에 **단위 필수**: (mag), (px), (e⁻/ADU), (″)
- T4. 최소 폰트: 1단 폭 88mm 축소 기준 **7pt 이상** (현 설정 재검산 필요)
- T5. 그림마다 **alt text** 준비 (RASTI 신규 접근성 요건)

**V. 시각 규칙**
- V1. 이중축은 **같은 양의 다른 단위**일 때만 (완전도↔recovered %는 OK, 산포↔깊이는 ✗)
- V2. 팔레트·마커·선폭은 `apex_paper_style.py` 단일 소스에서만
- V3. 색맹 안전 + 흑백 인쇄 판독 가능(선종류로도 구분)
- V4. 격자 최소, 여백 균일, 패널 간 축 정렬

**N. 번호 규칙**
- N1. **파이프라인 순서로 재번호** (§3 v4 순서). 파일명도 새 번호로
- N2. 본문·캡션·Data availability의 그림 참조 **전수 갱신** (현재 "그림 5–4" 같은 비문 존재)
