## 1. 회고 — 무엇이 반복해서 틀렸나

지난 세션들에서 그림 관련 지적이 **전부 사용자에게서 나왔고, 전부 옳았다.** 내가 자체적으로
잡아낸 것은 수치 추적(철칙 #12)뿐이고, **표현·출처·표본에 대해서는 매번 사후 대응**이었다.
같은 병이 그림마다 재발했으므로 개별 수정이 아니라 규칙으로 막아야 한다.

### 잘 작동한 것 (유지)

- **설명 안 되는 수치를 그 자리에서 분해**: 2.75 mag 격차를 σ·FWHM²로 0.00 오차 분해, 합성 S/N₅₀=5.19
  발견해 자기 주장 철회, 순환 모드 2건(마스터 자기선택·최심프레임) 발견·차단.
- **원문 그림 직접 확인**: Kessler/Stetson 실제 그림을 받아보고 귀속을 정정(DAOPHOT엔 완전도 그림
  자체가 없음 등). 인용 전 확인 습관은 계속.
- **지식그래프 RAG**: 긴 문서 재독 대신 grep 조회.

### 근본 원인 진단

R1·R2·R5는 **"그림을 만든 뒤 사람이 본다"에 의존**했기 때문에 생겼다. 규칙이 문서(FIGURE_SPEC)에만
있고 **코드에 강제되지 않아** 매번 빠졌다. → 이번 계획의 핵심은 **기계 검사 가능한 규격**으로 바꾸는 것.

## 3. 규격 — 데이터 명세 블록 (모든 그림 의무)

각 그림은 패널 안 또는 그림 하단에 아래를 **반드시** 표기한다. `apex_paper_style.py`에
`provenance_block(ax, ...)` 헬퍼를 추가해 코드로 강제하고, 감사 스크립트가 누락을 실패로 잡는다.

```
[데이터 종류] 실측 | 합성(verification)
[출처]       사이트·기기·기간   예: "Moravian C3-61000 · 2026-02~06"
             합성이면 "APEX synthetic generator, seed=…"
[대상·규모]  예: "M67/NGC6811/M13 · 7 single exposures · 3,000 injections each"
[재현]       스크립트명 + 데이터 경로
```

전역 지침(철칙 #6 "데이터 출처 정밀 표기: 사이트+기기+기간")의 코드화다.

## 4. 실행 계획

### P0 — 즉시 (원고 정합성 위협)

1. **`provenance_block()` 헬퍼 + 감사 스크립트**
   - `apex_paper_style.py`에 헬퍼 추가, `scripts/audit_figures.py`가 전 그림 스크립트를 검사해
     명세 누락 시 실패. CI 성격의 게이트.
2. **fig3 전면 재설계** (사용자 명시 지시)
   - `trials=4` → 통계적으로 충분한 수(≥30)로. 각 점에 **부트스트랩 오차막대**.
   - 이중 y축 폐기 → 패널 분리. 제목을 message-first로("aperture optimum near 1.2×FWHM" 등).
   - (c) 톱니가 노이즈였는지 실제 구조였는지 **재실행으로 판정**하고 결과를 그대로 기록.
   - 스윕 점 5~6개 → 촘촘히. 데이터 명세 블록 필수.
3. **fig5 교체**: NGC457 278별 → **NGC6811 499별**(`fig_iraf_crosscheck.py`) 로 `.tex` 갱신.
   본문 수치(MAD 0.0043 → 0.0097 등)도 함께 정정.
4. **fig2·fig4·fig6 명세 블록 추가** (재계산 불필요, 표기만).

### P1 — 확장 (사용자 지시: fig1 대상/개수)

5. **fig1 기기 확장**: LCO **Sinistro CCD** + **QHY600 CMOS** 실측 프레임에 동일 주입 실행.
   - 목적: S/N₅₀ 법칙이 **다른 망원경·다른 검출기에서도 성립**함을 실증 → 논문의 최대 약점인
     "전 데이터가 단일 카메라"를 완전도 축에서만큼은 정면 돌파.
   - gain·ZP는 각 기기 헤더/실측값 사용(하드코딩 금지). 실패해도 결과 그대로 보고.
6. **fig1 대상 확장**: M5(step7 없음) 재처리 또는 M3 검토 — 5에서 기기축이 확보되면 우선순위 하향.

### P2 — 후속

7. fig7~10 명세 블록 + FIGURE_SPEC 준수 여부 재점검.
8. `.tex`/`.md` 이중 원고 정합 자동 점검(수치 대조 스크립트).

## 5. 검증 규칙 (이번엔 반드시)

- 각 그림 재작업 후 **PNG를 직접 열어 확인**한 뒤에만 완료 보고(철칙 #1).

- 수치가 바뀌면 `.tex`·`.md`·캡션 3곳을 **같은 커밋에서** 갱신(R6 재발 방지).
