**전에** 돌린 전 대상 재처리다. 최적화 후 parity 를 이 결과에 대고 판정하며,

## 측정하지 못한 것

**peak RSS 를 재지 않았다.** 성능 감사 프로토콜이 요구하는 항목인데 이 실행에는
계측을 걸지 않았다. 최적화 후 clean run 에서는 반드시 남겨야 하며, Step 0 의
streaming 전환이 정확히 이 값을 겨냥한 변경이므로 **before 값이 없으면 그 변경의
효과를 수치로 말할 수 없다.**

보완책: baseline 을 통째로 다시 돌리지 않고, 고정 subset(예: M67 30 프레임)만
현재 코드로 재실행하면서 계측하면 before 값을 얻을 수 있다. Step 0 는 멱등이므로
새 출력 폴더에 돌리면 baseline 을 건드리지 않는다.
