# 수업 사용자 경험 조사

「항성과 항성계」 수업에서 APEX 와 AstralImage 를 쓴 뒤 받은 익명 설문.
구글 폼 응답을 옮긴 것이고, **타임스탬프는 버렸다** — 소수 인원 수업이라
응답 시각이 준식별자가 될 수 있다.

```bash
python -X utf8 validation/classroom_survey/analyze.py
```

| 파일 | 무엇 |
|---|---|
| `responses.tsv` | 익명 응답 8 명 |
| `items.tsv` | 문항 전문 (표 라벨은 줄인 것이라 원문은 여기서 본다) |
| `analyze.py` | 표를 만든다. **본문 수치를 하드코딩하지 말고 여기서 뽑는다** |

- 응답 8 명 · 리커트 1~5
- 사전 분석 경험: **7/8 명이 2 이하** (1 = 없음)
- 7/8 명이 두 프로그램을 다 썼고, 한 명은 AstralImage 만 썼다고 답했다

## 이 자료가 뒷받침하는 것

**1. 저자가 아닌 사람 여덟이 실제 관측자료로 워크플로를 완주했다.**
심사에서 「저자가 재면 증거가 안 된다」고 지적된 자리에 놓을 수 있는 유일한 자료다.
그리고 응답자 대부분이 사전 경험이 없다 — 접근성 논지가 겨냥하는 바로 그 집단이다.

**2. 점수가 「편했다」와 「이해했다」로 갈린다.** 이게 이 자료에서 가장 값어치 있는
부분이고, 자화자찬이 아니라 우리 한계를 가리킨다.

| APEX 항목 | 평균 |
|---|---|
| 자동 측광과 결과 시각화가 유용 | 4.62 |
| 여러 단계를 한 프로그램에서 해서 편리 | 4.62 |
| 실제 관측자료 탐구 활동에 활용 가능 | 4.62 |
| 단계형 구성이 분석 절차 이해에 도움 | 4.25 |
| 구경 측광으로 별 밝기를 재는 과정을 이해 | 4.00 |
| **이미지에서 측광·CMD·광도곡선까지 따라갈 수 있었다** | **3.88** |

높은 셋은 전부 편의에 관한 것이고 낮은 둘은 전부 「과학을 이해했나」에 관한 것이다.
**도구가 작업을 돌아가게 만든 것과 사용자가 그 작업을 이해한 것은 다르다.**

**3. 자유 서술 셋이 따로따로 같은 것을 요구했다** — 단계별 설명서, 그리고
**오류가 났을 때 무엇이 문제인지 알려주는 기능**. 두 번째는 목차의 §2.12
(실패했을 때 무엇이 보이나)를 사용자가 먼저 요구한 것이다. 우리가 좋은 절이라고
판단한 것보다 훨씬 강한 근거다.

같이 봐야 할 것: 매뉴얼이 `parameters.toml` 을 17 번 가르치는데 코드는 2026-08-06
부터 JSON 만 읽는다. **문서가 있는 자리는 틀려 있고, 사용자는 문서를 달라고 한다.**

「사용법 설명이 활동을 수행하기에 충분했다」는 평균 4.38 인데 **범위가 2~5** 로,
만족도 문항 가운데 유일하게 2 가 나왔다.

## 이 자료가 뒷받침하지 못하는 것 — 본문에 그대로 밝힌다

- **N = 8, 대조군 없음, 수업 진행자가 저자다.** 응답 편향을 배제할 수 없다.
- **인식 조사이지 수행 측정이 아니다.** 아무도 「올바른 CMD 를 얻었는가」를 재지
  않았다. 만족도는 정확도의 증거가 아니다.
- **시간을 재지 않았다.** 설치·완주 비용은 여전히 미측정이고, 이 설문으로 답할 수
  없다. 그건 따로 재야 한다.
- **수업의 전처리는 AstralImage 로 했다.** 설문이 AstralImage 를 「전처리 및 이미지
  후처리용」으로 부르고 전처리 문항도 그쪽에 붙어 있다. 그러므로 **APEX Step 0
  (검출기 보정)은 수업에서 쓰이지 않았다** — 「학생이 raw 부터 완주했다」고 쓸 수 없다.
  APEX 쪽 근거는 Step 1 이후에 대한 것이다.
- 한 명은 AstralImage 만 썼다고 답했으나 APEX 문항에도 응답했다. **APEX 표의 유효
  N 을 8 로 볼지 7 로 볼지 본문에 밝힌다.**

## 원고에 넣기 전에 확인할 것

- **동의·연구윤리** — 학생 응답을 논문에 싣는다. 익명이고 식별자가 없지만, 수집
  시점에 동의를 받았는지와 기관 심의가 필요한지를 확인해야 한다. PASP 가 물을 수 있다.
- **AstralImage 결과를 어디까지 실을지** — 별개 소프트웨어(별도 레포)다. 수업이 둘 다
  썼으니 그 사실은 밝혀야 하지만, AstralImage 문항 표까지 APEX 논문에 실을 이유는 없다.
