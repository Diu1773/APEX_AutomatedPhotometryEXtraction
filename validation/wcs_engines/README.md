## 부수 발견 — 외부 솔버의 선택은 refine 후 거의 무의미하다

astap 과 astnet 의 잔차가 **8 프레임 중 7 개에서 완전히 동일**하다(넷째 자리까지).
원인은 APEX 가 외부 해를 자체 Gaia 매칭으로 refine 하기 때문이다
(`refine = m1=600`, 두 트리 모두 `match_n = 600`). 즉 **외부 솔버의 기여는
사실상 초기 추정값이고, 최종 정확도는 APEX 의 refine 이 결정한다.**

이는 §3.6 서술에 반영해야 한다 — "ASTAP 대비 정확"이 아니라 "ASTAP/anet 의
초기해를 같은 refine 에 태워도 내장 경로가 더 정확"이 맞는 문장이다.

## 명시할 교란요인

**내장은 678–1,147 개 매칭을 쓰고 외부 경로는 600 개로 상한이 걸려 있다**
(`match_n`). 정확도 우위가 **솔버 자체 때문인지 매칭 수 때문인지 이 자료로는
가릴 수 없다.** 외부 경로의 상한을 풀거나 내장을 600 개로 묶어 다시 재야
확정된다. 논문에 쓸 때 이 조건을 함께 적지 않으면 과대주장이 된다.

또한 내장은 프레임마다 SIP 차수를 다르게 잡는다(0, 3, 3 …). 외부 경로는
3 으로 고정이다. 이것도 잔차 차이에 기여할 수 있다.
