# ASteCA 교차검증 — 같은 별, 같은 이소크론, 다른 순전파 모델

APEX 의 M67 이소크론 적합이 문헌값을 못 맞췄다(나이 2.80 Gyr · [M/H] −0.50 ·
E(B−V) 0.173 · 거리지수가 시차 창 아래 끝에 붙음 · MCMC acceptance 0.126).
설명이 둘인데 처방이 정반대다:

- **자료가 못 정한다** — g/r/i 만으로는 금속량·소광 축퇴가 안 풀리고 어떤
  도구도 못 한다
- **APEX 의 우도나 샘플러가 문제다**

독립적으로 작성된 두 번째 순전파 모델에 **같은 별과 같은 격자**를 주면 갈린다.

## 결과

| | 나이 | [M/H] | E(B−V) | 거리지수 |
|---|---:|---:|---:|---:|
| APEX (MCMC, EEP 보간 + 전색상 공분산 + 시차 사전분포) | 2.80 Gyr | **−0.504** | **0.173** | 9.633 |
| ASteCA 0.7 (합성 성단 + Poisson likelihood ratio) | 3.20 Gyr | **−0.246** | **0.097** | 9.634 |
| 문헌 M67 | ~4 Gyr | ~0.0 | ~0.04 | ~9.7 |

**두 모델이 같은 방향으로 틀린다** — 금속량은 낮게, 소광은 높게, 나이는 젊게.
거리지수는 **둘 다 시차 창 [9.631, 9.751] 의 아래 끝**에 붙는다.

## 판정

**주된 원인은 자료의 축퇴이지 APEX 의 결함이 아니다.** 독립 구현이 같은
자료에서 같은 코너로 간다. 이는 메모리에 기록된 "U/B/V 를 한 표준계로 재앵커해야
M67 이 문헌값으로 돌아온다"와 맞물린다 — **U 밴드 없이는 풀리지 않는다**를
외부 도구가 확인해 준 셈이다.

**다만 APEX 가 약 2 배 더 멀리 나간다**([M/H] −0.50 vs −0.25, E(B−V) 0.173 vs
0.097). 자료 한계가 주범이어도 APEX 쪽에 개선 여지가 남는다.

**별도 신호**: 두 도구 모두 거리지수 창의 아래 끝에 붙었다. 측광이 Gaia 시차보다
가까운 거리를 원한다는 뜻이며, 보정 등급의 영점·색항을 의심할 근거다.

## 이 비교가 무엇이고 무엇이 아닌가

- ASteCA 0.7 은 합성 성단 생성과 Poisson likelihood ratio(Tremmel+ 2013)를
  제공하지만 **2015 년 논문의 유전 알고리즘을 노출하지 않는다.** 탐색기는
  이쪽에서 작성했다(scipy `differential_evolution`). 따라서 이것은
  **고정된 자료 위에서 순전파 모델과 우도를 비교**한 것이지 완제품 도구 둘의
  비교가 아니다
- 별 목록은 거의 같으나 정확히 같지는 않다. APEX 의 측성 멤버 컷(고유운동
  ±3σ, 시차 1.153 ± 3×0.05)을 재현해 517 별을 얻었고, APEX 는 여기에
  `--max-stars 500` 등을 더 적용해 409 별로 적합했다
- 결과는 합성 표본 크기에 안정적이다 — 100 개와 517 개가 **같은 값**을 냈다.
  잡음 한계가 아니다

**두 도구가 동일한 이론 모델을 쓰므로 결과 차이가 모델 차이로 오염되지 않는다.**

## 후속 — 격차의 원인은 쌍성 미모델링이다 (2026-08-10)

APEX 가 ASteCA 보다 약 2 배 더 멀리 나간 원인을 두 단계로 갈랐다.

### 1단계 — 샘플러가 아니다

APEX 의 첫 적합은 `convergence_ok = False` (acceptance 0.126) 였다. 체인을
4 배로 늘려 다시 돌렸다(32 walkers × 2000 → 64 × 8000, burn 600 → 2000,
1,947 s):

| | 32×2000 | 64×8000 |
|---|---:|---:|
| 나이 (Gyr) | 2.805 | **2.802** |
| [M/H] | −0.504 | **−0.502** |
| E(B−V) | 0.173 | **0.174** |
| 거리지수 | 9.633 | 9.633 |
| acceptance | 0.126 | **0.228** |

acceptance 는 정상 범위(0.15–0.7)로 올라왔는데 **값은 그대로다.** 68 % 구간도
좁다([M/H] [−0.518, −0.497], E(B−V) [0.172, 0.200]). **APEX 는 확신을 갖고
틀리고 있다 — 불확실성이 아니라 편향이다.**

(`convergence_ok` 가 여전히 False 인 것은 이제 자기상관시간 조건 때문이다 —
`get_autocorr_time` 이 실패해 `autocorr_time: None` 이다. 별건.)

### 2단계 — 쌍성을 끄면 ASteCA 가 APEX 쪽으로 온다

미분해 쌍성은 주계열보다 최대 0.75 등급 위에 앉아 주계열을 위쪽·붉은쪽으로
넓힌다. 모델에 그 폭이 없으면 적합기는 **소광을 올리고 금속량을 낮춰서**
메울 수밖에 없다. ASteCA 는 합성 성단에 쌍성을 넣고(`alpha=0.09, beta=0.94`),
APEX 는 이소크론 곡선 하나에 맞춘다. 같은 자료에서 ASteCA 의 쌍성만 껐다:

| | 나이 | [M/H] | E(B−V) | 거리지수 |
|---|---:|---:|---:|---:|
| ASteCA **쌍성 있음** | 3.20 Gyr | −0.246 | 0.097 | 9.634 |
| ASteCA **쌍성 없음** | 2.26 Gyr | **−0.406** | **0.186** | 9.652 |
| APEX (쌍성 미모델링) | 2.80 Gyr | **−0.502** | **0.174** | 9.633 |

**쌍성을 끈 ASteCA 가 APEX 와 같은 코너로 간다.** 소광은 0.186 vs 0.174 로
거의 겹치고, 금속량도 −0.41 로 −0.50 쪽으로 크게 이동한다.

### 결론과 남는 것

**격차의 주된 원인은 APEX 이소크론 우도에 쌍성 계열이 없다는 것이다.**
개선 지점이 특정됐다 — 우도에 "단일성 또는 질량비 q 의 쌍성" 혼합을 넣으면
된다. 합성 성단 생성까지 갈 필요는 없다. 다만 이는 step12 우도 모델의 실제
변경이다.

**그러나 쌍성을 넣어도 문헌값에는 못 미친다.** ASteCA 가 쌍성을 켜고도
[M/H] −0.25 (문헌 0.0), E(B−V) 0.097 (문헌 0.04) 이다. 즉:

- **APEX ↔ ASteCA 격차** = 쌍성 미모델링 (고칠 수 있음)
- **두 도구 ↔ 문헌 격차** = g/r/i 만으로 풀리지 않는 나이–금속량–소광 축퇴
  (U 밴드가 필요하다는 기존 기록과 일치)

두 원인은 독립이며 처방이 다르다.
