# ASteCA 교차검증 — 같은 별, 같은 이소크론, 다른 순전파 모델

APEX 의 M67 이소크론 적합이 문헌값을 못 맞췄다(나이 2.80 Gyr · [M/H] −0.50 ·
E(B−V) 0.173 · 거리지수가 시차 창 아래 끝에 붙음 · MCMC acceptance 0.126).
설명이 둘인데 처방이 정반대다:

- **자료가 못 정한다** — g/r/i 만으로는 금속량·소광 축퇴가 안 풀리고 어떤
  도구도 못 한다
- **APEX 의 우도나 샘플러가 문제다**

독립적으로 작성된 두 번째 순전파 모델에 **같은 별과 같은 격자**를 주면 갈린다.

## 결과

| | 나이 | [M/H] | E(B−V) | 거리지수 |
|---|---:|---:|---:|---:|
| APEX (MCMC, EEP 보간 + 전색상 공분산 + 시차 사전분포) | 2.80 Gyr | **−0.504** | **0.173** | 9.633 |
| ASteCA 0.7 (합성 성단 + Poisson likelihood ratio) | 3.20 Gyr | **−0.246** | **0.097** | 9.634 |
| 문헌 M67 | ~4 Gyr | ~0.0 | ~0.04 | ~9.7 |

**두 모델이 같은 방향으로 틀린다** — 금속량은 낮게, 소광은 높게, 나이는 젊게.
거리지수는 **둘 다 시차 창 [9.631, 9.751] 의 아래 끝**에 붙는다.

## 판정

**주된 원인은 자료의 축퇴이지 APEX 의 결함이 아니다.** 독립 구현이 같은
자료에서 같은 코너로 간다. 이는 메모리에 기록된 "U/B/V 를 한 표준계로 재앵커해야
M67 이 문헌값으로 돌아온다"와 맞물린다 — **U 밴드 없이는 풀리지 않는다**를
외부 도구가 확인해 준 셈이다.

**다만 APEX 가 약 2 배 더 멀리 나간다**([M/H] −0.50 vs −0.25, E(B−V) 0.173 vs
0.097). 자료 한계가 주범이어도 APEX 쪽에 개선 여지가 남는다.

**별도 신호**: 두 도구 모두 거리지수 창의 아래 끝에 붙었다. 측광이 Gaia 시차보다
가까운 거리를 원한다는 뜻이며, 보정 등급의 영점·색항을 의심할 근거다.

## 이 비교가 무엇이고 무엇이 아닌가

- ASteCA 0.7 은 합성 성단 생성과 Poisson likelihood ratio(Tremmel+ 2013)를
  제공하지만 **2015 년 논문의 유전 알고리즘을 노출하지 않는다.** 탐색기는
  이쪽에서 작성했다(scipy `differential_evolution`). 따라서 이것은
  **고정된 자료 위에서 순전파 모델과 우도를 비교**한 것이지 완제품 도구 둘의
  비교가 아니다
- 별 목록은 거의 같으나 정확히 같지는 않다. APEX 의 측성 멤버 컷(고유운동
  ±3σ, 시차 1.153 ± 3×0.05)을 재현해 517 별을 얻었고, APEX 는 여기에
  `--max-stars 500` 등을 더 적용해 409 별로 적합했다
- 결과는 합성 표본 크기에 안정적이다 — 100 개와 517 개가 **같은 값**을 냈다.
  잡음 한계가 아니다

## 재현

```bash
pip install asteca                      # 0.7.0, Python >= 3.12, 별도 venv 권장
python -X utf8 m67_compare.py
```

이소크론은 APEX 가 이미 갖고 있는 PARSEC CMD 3.9 SDSS 격자에서 나이 1–8 Gyr ·
[M/H] −1.0~0.5 로 자른 부분집합을 쓴다(`isochrone/PARSEC/sdss/iso_data_cmd39.dat`).
**두 도구가 동일한 이론 모델을 쓰므로 결과 차이가 모델 차이로 오염되지 않는다.**
