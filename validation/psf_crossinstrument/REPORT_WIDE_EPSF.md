# 광시야에서 단일 EPSF 가 시야 전체를 커버하는가

**2026-07-30** · 자료: **M45**, LCO 0.4 m tfn / sq32 = QHY600 CMOS **풀프레임**
(6388×9576 = 61.7 MP, **2.0°×1.3°**, 0.74″/px) · B×10 + V×10, 120 s, 2025-01-14,
archive.lco.global · 보정: APEX 산술 + 우주선 제거

## 왜 봤나

APEX 의 Step 8 은 **프레임당 EPSF 하나**를 만든다(`model_mode=per_frame`).
`psf_policy.grid_size` 는 참조별을 시야에 고르게 뽑기 위한 것이지
(`select_spatially_balanced`) 격자별 PSF 모델이 아니다. 시야가 넓어질수록
가장자리 수차(코마·비점)를 단일 모델이 못 따라갈 수 있으므로 유효 범위를
실측해야 했다. 우리 Moravian 시야(0.43°)의 **4.6배**가 이 자료다.

## 결과 — 넓어도 버틴다

| | Sinistro 26′ | **M45 2.0°×1.3°** |
|---|---:|---:|
| 프레임 / 별 | 1 / 187 | **19 / 50,607** |
| Δmag 중심(r<0.3) | −0.0057 | +0.0038 |
| Δmag 가장자리(r>0.7) | +0.0063 | +0.0083 |
| **중심→가장자리 이동** | **12 mmag** | **4.5 mmag** |
| MAD | 0.019 → 0.032 (1.7배) | 0.025 → 0.031 (**1.27배**) |
| qfit/noise | 0.902 → 0.930 | 0.925 → 0.965 |

**시야가 4.6배 넓은데 열화는 오히려 절반이다.** 앞서 Sinistro 에서 본 큰 값은
1프레임 187별의 통계 부족이었고, 5만 별로 잰 이쪽이 믿을 만하다.

반경 추세(`fig_wide_epsf_m45_wide.png` 오른쪽)를 보면 **r < 0.7 까지 완전히
평평**하고 모서리에서만 +0.03 까지 오른다. → **격자 EPSF 가 필요하다는 근거는
이 자료에서 나오지 않는다.** 단일 EPSF 로 2.0°×1.3° 를 덮을 수 있다.

### 다만 순수 반경 대칭은 아니다

Δmag 격자 지도는 아래쪽이 +, 위쪽이 − 인 **세로 방향 구배**를 보인다. 반경만의
함수가 아니므로 광학 정렬이나 검출기 기울기 쪽 신호로 읽어야 한다. 크기가
5 mmag 수준이라 대부분의 측광에서는 무시할 수 있지만, mmag 정밀도를 노리면
고려해야 한다.

## 실사용 한계 — 광시야는 메모리를 먹는다

20장 중 **1장이 검출 단계에서 실패**했다.

```
[DetectionWorker] Error in detect_single(pp_m45lco-0005-B.fit):
Unable to allocate 467. MiB for an array with shape (6388, 9576) and data type float64
```

61.7 MP 를 float64 로 잡으면 배열 하나가 467 MB 이고, 워커가 여럿이면 16 GB
RAM 으로는 모자란다. 검출을 float32 로 하면 절반이 된다. **광시야 + 멀티워커의
실사용 한계**로 기록한다(자동 복구 없이 그 프레임만 조용히 빠진다 —
`psf_output_signature.json` 이 안 써지므로 완주 여부는 확인할 수 있다).

격자 셀당 별 수가 충분하다.

## 전 구간 완주 확인 — 되지만 M45 로 CMD 는 못 한다

Step 0 부터 12 까지 한 번도 멈추지 않고 통과했다(61.7 MP × 20장). 영점보정도
6,045 별에 붙었고 이소크론 MCMC 도 끝났다. **파이프라인 완주는 성공.**

그러나 **물리 결과는 버려야 한다.**

| | 적합값 | 문헌 M45 |
|---|---:|---:|
| (m−M) | **11.54** (2,030 pc) | **5.6–5.7** (136 pc) |
| 나이 [Gyr] | 0.023 | 0.10–0.13 |
| [M/H] | +0.309 | ~0.0 |
| E(B−V) | 0.732 | ~0.03 |

원인은 **포화**다. 마스터 카탈로그를 보면:

| | |
|---|---:|
| Gaia **G < 8** 별 (M45 밝은 멤버) | **0 개** |
| G < 10 | 3 개 |
| 마스터 G 범위 | 9.51 – 18.00 |
| 시차 6–9 mas (M45 멤버권) | 178 / 3,541 |
| 시차 중앙값 | **0.66 mas** (배경) |

플레이아데스 멤버는 V 2.9–6 인데 120 s 노출에서 전부 포화해 검출·측광에서
빠졌다. 남은 3,363 개 배경 별이 다수라 멤버십이 그쪽을 성단으로 잡았고,
시차 0.498 mas(≈2 kpc)를 성단 거리로 삼았다.

**APEX 결함이 아니라 자료–대상 부적합이다.** 가까운 성단을 긴 노출로 찍으면
멤버가 포화한다. M45 로 CMD 를 하려면 10–20 s 노출이 필요하다 (아카이브에
`sq40 2024-12-02` B×45 + V×45 **10 s** 세트가 있다).

→ **M45 의 값어치는 광시야 EPSF 검증이고 그것은 성공했다.** CMD·이소크론
결과는 이 자료로 쓰지 않는다.
