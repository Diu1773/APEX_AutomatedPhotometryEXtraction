# PSF 측광 완성 — 최종 결과

**2026-07-29 ~ 30** · 목표: Codex 로 구현만 해두고 검증하지 않았던 PSF 측광(Step 8)의
실사용·헤드리스·타 기기 동작을 확인한다.

## 1. 한 줄 결론

**PSF 측광은 검출기 4종·시야 0.43°~2.0°·혼잡장과 산개장 모두에서 동작한다.**
그 과정에서 **코어 기본값 2건이 틀려 있었고**(우주선 제거 꺼짐, ePSF 참조별 방어선
없음) 둘 다 고쳤다. 고치기 전에는 CMOS 자료에서 **PSF 플럭스가 구경의 32%** 로
떨어지면서도 "flux sanity OK" 를 찍었다.

## 2. 검증 범위 — 검출기 4종

| 검출기 | 자료 | 프레임 | PSF vs 구경 MAD |
|---|---|---:|---:|
| Moravian C3-61000 (CMOS) | M13 구상성단 | 15 | 0.042 |
| Moravian C3-61000 | NGC6811 산개성단 | 21 | 0.020 |
| **LCO QHY600 (CMOS)** | M67 산개성단 | 10 | **0.0074** |
| LCO QHY600 풀프레임 | M45 광시야 2.0°×1.3° | 19 | 0.031 |
| **LCO Sinistro (CCD 4-amp)** | NGC 5985 은하 필드 | 1 | 0.027 |
| **LCO SBIG STL-6303 (CCD)** | M67 U·B·V | 8 | — |

프레임간 재현성: M13 0.051 · M67 LCO **0.045** · NGC6811 0.059 mag.

## 3. 찾아서 고친 것

| 결함 | 증상 | 조치 |
|---|---|---|
| **우주선 제거가 꺼져 있었다** | CMOS 검출의 16~40% 가 1픽셀 스파이크. ePSF 가 2.75배 좁아지고 PSF 플럭스 32% | 기본 on (`d9ad1ef`) |
| **ePSF 참조별 방어선 없음** | 형태 컷이 상시 완화되어 우주선이 참조별로 뽑힘 | FWHM 하한 + PSF 대칭 판정 (`001ea94`) |
| Johnson U 매핑 부재 | U 자료를 받아도 이소크론 그리드를 못 읽음 | `PARSEC_ISO_COL` 에 UXmag 추가 (`f70cfde`) |
| 헤드리스에서 ASTAP 도달 불가 | 남천 대상이 안 풀림 | `[wcs] engine` 키 (`15787a9`) |
| GUI 에 강제측광 비율 없음 | PSF/구경 비교를 오독 | Step 8 표에 `Forced %` (`6897f3c`) |
| 검출한계 테스트 경로 | 재처리 후 항상 스킵 | `calibrated/` → `sci/` |

## 4. 우주선 제거 — 검증 완결

표준 관행인데 우리만 꺼져 있었다(BANZAI 는 자기 e91 에서 단일픽셀 스파이크의
**46.7%** 를 지운다). 켠 뒤 다섯 축으로 검증했다.

| 축 | 결과 |
|---|---|
| **측광 영향** | M13 **+0.0002** · NGC6811 **+0.0012** mag (MAD 0.0038/0.0039, 3만 쌍) |
| **별 손상** | 코어 마스크된 6% 만 −0.44%. 94% 는 하늘 환형이 깨끗해져 **오히려 정확해짐** |
| **효과** | 1프레임 검출 −24~49%, **전프레임 검출은 −1개** |
| **보정 무결성** | CR 켠 뒤에도 BANZAI 대조 0.35~0.85% 유지 |
| **완전도** | 하늘 σ −0.7~1.4% → m50 +0.007~0.016 mag. 모델 오차(±0.047)의 **1/3~1/7** → 재보정 불필요 |

→ **픽셀을 바꾸는데 측광은 안 바뀌고, 진짜 별은 안 없어지고, 우주선만 사라진다.**

## 5. 광시야 EPSF — 단일 모델로 충분

M45 2.0°×1.3°(61.7 MP, 19프레임, 50,607 별):
중심→가장자리 Δmag **4.5 mmag**, MAD 1.27배, r<0.7 까지 완전히 평평.
→ **격자 EPSF 가 필요하다는 근거는 이 자료에서 나오지 않는다.**
위치기반 EPSF 는 향후 구현으로 남겼다(`REPORT_WIDE_EPSF.md` 「향후 구현」).

## 6. 미해결 / 향후

- **이소크론 [M/H] rail** — 어느 자료에서도 금속결핍 쪽으로 rail 한다. U−B 를
  넣으면 **더 나빠진다**(Gaia→U 변환이 σ=0.200 mag). U 표준등급(Landolt/Stetson)
  확보가 선행 조건. `REPORT_UB_DEGENERACY.md`
- **CR 재처리 잔여** — M3(오염 15.4%) · M67 · M5. 방법은 M13·NGC6811 에서 확립.
- ~~`keep_max` 가 정렬 없이 자른다~~ → **오독이었다.** 두 경로 모두 자르기 전
  `np.argsort(flux)[::-1]` 로 밝기순 정렬한다(`detection.py:610, 783`). 어두운
  별부터 버리는 예측 가능한 절단이고 완전도 모델이 다루는 편향이다. M45 에서
  10/19 프레임이 걸렸을 때 y 분포가 정상이었던 것도 설계대로였다.
- ~~Step 8 리포트가 헤드리스에서 안 나온다~~ → **해결(전부).** 모듈 함수 넷을
  빼고 창이 그것을 쓰게 했다 — `load_psf_qc_inputs` · `build_ap_psf_comparison` ·
  `render_psf_final_diagnostics` · `export_psf_qc_products`. 헤드리스가 **6종**을
  낸다: 비교표·QC요약·프레임QC·잔차/코어 그림·최종진단 그림·진단 JSON.
- **그 과정에서 실제 버그 발견** — 비교 병합이 `mag_ap` 를 하드코딩했는데
  Step 7 은 그 이름을 쓴 적이 없다(`mag_inst`). GUI 의 「구경 vs PSF」 탭이 늘
  "All magnitudes are NaN" 만 띄우고 있었다. 폴백을 넣어 고쳤다 —
  M13 12,892행 Δ +0.0754 · NGC6811 20,762행 Δ +0.0687.
- **GUI 실구동 확인** — 코드 감사는 끝났고(파라미터 왕복 16/16 무손실) 실제
  구동은 보류.
